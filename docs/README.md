# 📋 Documentation Structure

This directory contains all project documentation, organized by type.

## 📁 Folder Organization

### 🔹 `/phases/`
Phase-specific documentation and summaries:
- **PHASE4_SUMMARY.md** – Uncertainty Quantification implementation and results
- **PHASE5_SETUP.md** – n8n integration setup guide

### 🔹 `/tracking/`
Project progress and status tracking:
- **PROGRESS.md** – Overall project progress report with phase completion status
- **PHASE_TRACKING.md** – Detailed phase checklist and tracking
- **STATUS_REPORT.md** – Status updates on specific issues/fixes

### 🔹 `/daily-logs/`
Daily development logs organized by date and phase:
- `2026-02-12__Phase1__Core_Detection_and_Queue_Logic.md`
- `2026-02-16__Phase2__GUI_Stability_Fixes.md`
- `2026-02-16__Phase3__YOLO26_Migration.md`

- `TEMPLATE.md` – Template for creating new daily logs

## 🎯 Quick Navigation

- **Getting Started?** → Start with `/README.md` in the root folder
- **Tracking Progress?** → See `tracking/PROGRESS.md` or `tracking/PHASE_TRACKING.md`
- **Understanding a Phase?** → Check `phases/` or `daily-logs/`
- **Checking Recent Work?** → See `tracking/STATUS_REPORT.md` or latest in `daily-logs/`
