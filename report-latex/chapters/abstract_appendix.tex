\chapter*{Abstract}

This final year project addresses real-time waiting-time estimation in checkout queues from video streams.
The proposed system combines object detection (YOLO), multi-object tracking (ByteTrack), polygon-based zone filtering, and an M/M/1 queuing model to compute key metrics ($\lambda$, $\mu$, $W$).
To improve decision reliability, Bayesian uncertainty quantification is integrated through 95\% credible intervals.

The implementation demonstrates the feasibility of automated queue monitoring with a real-time dashboard, CSV logging, and webhook integration with n8n.
The approach supports operational decision-making while explicitly reporting confidence levels of estimated metrics.

\vspace{0.5cm}
\noindent\textbf{Keywords:} Computer vision, YOLO, ByteTrack, queueing theory, M/M/1, Bayesian uncertainty, real-time monitoring.
