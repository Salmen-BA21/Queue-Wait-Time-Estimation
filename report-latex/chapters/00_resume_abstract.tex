\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This final year project addresses real-time waiting-time estimation in checkout queues from video streams.
The proposed system combines object detection with YOLO, multi-object tracking with ByteTrack, polygon-based spatial filtering, and an M/M/1 queueing model to estimate key indicators ($\lambda$, $\mu$, $W$).
To improve decision reliability, Bayesian uncertainty quantification is integrated through 95\% credible intervals.

The obtained results demonstrate the feasibility of automated queue monitoring with a real-time dashboard, CSV logging, and webhook integration with n8n.
The approach provides practical decision support while explicitly reporting confidence levels for estimated metrics.

\vspace{0.5cm}
\noindent\textbf{Keywords:} Computer vision, YOLO, ByteTrack, queueing theory, M/M/1, Bayesian uncertainty, real-time monitoring.
