\chapter{Conclusion and Future Work}
\chaptertoc

\section{General Conclusion}
This final year project enabled the design and development of a complete waiting-time estimation system from video streams.
The implemented architecture covers the full chain, from visual perception to business-oriented metrics, with integrated uncertainty quantification.

\section{Objective Review}
The main objectives are achieved:
\begin{itemize}
    \item people detection/tracking,
    \item queue-metric estimation,
    \item real-time display,
    \item logging and n8n integration,
    \item explicit uncertainty handling.
\end{itemize}

\section{Future Work}
Potential extensions include:
\begin{itemize}
    \item multi-zone support,
    \item advanced Telegram alerting through n8n,
    \item richer Streamlit dashboard,
    \item edge optimization (ONNX / TensorRT),
    \item broader statistical evaluation protocol.
\end{itemize}
